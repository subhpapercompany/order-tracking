# Subh Paper Company - Order Tracking & Production Management System

Enterprise Order Tracking, Notebook Production, Despatch, Papers, Board, Consumables & Financial Accounting Reconciliation System.

## Features
- **Centralized Database**: 100% serverless, zero-downtime database architecture in data/.
- **Kokuyo Camlin Financial Reconciliation**: Live open advance tracking, sales bill adjustment, paper mill creditors, rate difference claims, and FIFO finished goods valuation.
- **Finished Goods Stock Valuation**: Automatic calculation from SKUs to KG and FIFO paper purchase rate.
- **Multi-Vendor Support**: Kokuyo Camlin Ltd., ITC Ltd., and custom brands.
- **Tally-Inspired Hotkeys & Ergonomics**: Lightning fast accounting navigation.
