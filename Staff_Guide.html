GOOGLE DRIVE LIVE SYNC

🔗 1. App Kholen — Bas Yeh Link

https://subhpapercompany.github.io/order-tracking/
  1. Phone me Chrome kholein → upar wale box me link paste karke Go dabayein.
  2. Pehli baar page khule toh Bookmark / Add to Home screen kar lein (Chrome menu ➕ Add to Home screen) — agla baar icon se khulega.
  3. Upar green badge dikhe: ✅ Drive: Live (Connected) = sab sahi hai. Data aapke Google Drive se aa raha hai.
⚙️ Koi login, koi setting, koi pendrive nahi chahiye. Link kholte hi app khud Google Drive se jud jaati hai.

✍️ 2. Entry Staff (3 log) — Kya Kab Bharna Hai

WRITER 1 Daily Production Log

  • App → Entry Mode → 2. Daily Production Log
  • Roz subah ka production (kitne books bane) daalein.
  • Vendor (Camlin/ITC/Others) + Barcode + Qty + Date → Save.

WRITER 2 Despatch Log

  • App → Entry Mode → 3. Despatch Log
  • Jitna maal bheja (challan/LR) utni entry — kitna, kis party ko, kab.

WRITER 3 Attendance / Consumption

  • Attendance: roz ki haazri list.
  • Paper/Board/Consumables usage chahiye ho toh → 4. Consumption Entry.
💾 Save dabate hi data Google Drive par chala jaata hai — 4 second me baaki 9 logon ko dikhne lagega. Dobara upload karne ki zaroorat nahi.

📊 3. Report Viewers (7 log) — Bas Dekhna Hai

  • Link kholein → app Reporting Mode me aati hai → DashBoard, Order Sheet, Despatch, Papers, Reports…
  • Kuch bhi badalna nahi — sirf dekhna, print ya PDF/Excel lena.
  • Har 4 second data apne aap refresh hota hai — kisi entry writer ne entry ki, turant dikh jaayegi.
  • Print chahiye → 🖨 Print / 📄 PDF / 📊 Excel button.
